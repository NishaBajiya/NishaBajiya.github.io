Repositories

Code for the tools and databases I've built and the standalone packages released on PyPI. See my full profile on GitHub.

  • raghavagps/AntiBP3

    AntiBP3

    An improved method for predicting antibacterial peptides against Gram-positive, Gram-negative, and Gram-variable bacteria using machine learning.

  • raghavagps/EIPpred

    EIPpred

    Prediction of inhibitory peptides against E. coli and estimation of their minimum inhibitory concentration (MIC).

  • raghavagps/CPPsite3

    CPPsite3

    An updated, large repository of experimentally validated cell-penetrating peptides.

  • raghavagps/CPPLocPred

    CPPLocPred

    A hierarchical machine-learning framework for identifying cell-penetrating peptides and predicting their subcellular localization.

  • NishaBajiya/AptCancerDB

    AptCancerDB

    A curated knowledgebase and translational discovery platform for anticancer aptamers.

  • NishaBajiya/AptViralDB

    AptViralDB

    A repository of experimentally validated antiviral aptamers.

  • NishaBajiya/AptBacterialDB

    AptBacterialDB

    A comprehensive, manually curated database of antibacterial aptamers.

  • raghavagps/AntiCapt

    AntiCapt

    Predicting, designing, and scanning anticancer single-stranded DNA aptamers with fine-tuned HyenaDNA embeddings.
